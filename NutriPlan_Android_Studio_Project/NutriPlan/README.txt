NUTRIPLAN - ANDROID STUDIO PROJECT

Requirements:
- Android Studio
- Android SDK 35 (or allow Android Studio to install it)
- JDK 17

How to open:
1. Extract NutriPlan.zip.
2. Open Android Studio.
3. Choose File > Open.
4. Select the extracted NutriPlan folder.
5. Wait for Gradle sync.
6. Run the app on an emulator or Android phone.

Package: com.example.nutriplan
Language: Java
UI: XML

Screens:
- LoginActivity: name/password form and Toast validation.
- WelcomeActivity: receives the username using an explicit Intent.
- MainActivity: meal plan, food checkboxes, gender radio buttons and Toast.

The login is a classroom demonstration only; it does not authenticate against a server or database.
